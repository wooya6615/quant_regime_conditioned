## 국면 조건부(regime-conditioned) XGBoost pilot (2026-09)

### 배경
KASPER 프레임워크(Gumbel-Softmax 국면 감지 + 국면별 KAN + 심볼릭 회귀) 검토.
quant_unsupervised의 K-means 국면 분석이 "국면에 따라 수익 구조가 달라진다"는
전제를 뒷받침해서, KAN 없이 국면 조건부 모델링 자체의 유효성만 XGBoost로 검증.

### 결과 1: 064350 단독 (2785행)
5/5 시드 전부 음수 (AUC diff 평균 -0.0109, std/mean 30.5%). avg_n_regimes≈2.3,
train 300행이 국면당 ~150행으로 쪼개짐 -- GRU/TCN [실패]와 동일 패턴.

### 결과 2: 064350+118990 풀링 (addendum, 교집합 2144거래일 / train pool 평균 600행)
1/5 시드만 개선 (AUC diff 평균 -0.0030, std/mean 156.4% -- 노이즈 수준).
단독 대비 격차는 3.6배 축소(GRU/TCN의 3->50종목 확장과 같은 방향)했으나
사전등록 기준(4/5)에는 미달.

### 판정: [실패] (2연속, addendum 포함)
사전등록된 결정 규칙에 따라 3종목 확장 없이 여기서 종료. 격차 축소 추세는
관찰됐으나 표본을 늘리는 방향의 개선 속도가 느려(3.6배 데이터 증가로 격차
3.6배 축소 정도), 실용적 시간 대비 KOSPI200 규모까지 확장해도 4/5 통과를
보장할 근거 부족. KASPER 탐색 라인 완전 종료 -- Quantformer(거절), 국면
조건부 XGBoost(2연속 실패) 모두 이 프로젝트 데이터 규모에서는 "모델/구조를
더 쪼개거나 무겁게 만드는 방향"이 통하지 않는다는 공통 결론으로 수렴.
